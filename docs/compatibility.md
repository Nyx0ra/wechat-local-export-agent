# 兼容性与验证边界

支持范围：Python 3.12+；Apple 本地未加密且完成的备份；具有 Manifest.db Files 表、可识别联系人元数据、单个目标 Chat_<MD5> 表以及指定列布局的微信数据库。目标记录按 CreateTime、MesLocalID 排序。多账号必须显式选择，目标跨分片暂不支持。

时间：筛选以源 CreateTime 秒为准；输入需带时区，显示为用户配置的固定偏移，不自动处理地区夏令时规则。空窗口有效。未知方向显示原始值而不猜测身份。仅支持一对一会话；群成员身份和群聊专项验证不在此版本范围。

正文：明文字符串直接保留；WCDB 标志 2 且 Zstd 帧可用指定字典严格解压。未配置字典时保留占位及原始字节。非支持编码停止；这不等于 SQLCipher 解密。

媒体：原图由 Pillow 验证；转换后的 MP3/MP4 由 PyAV 逐帧检查。原始编码、部分应用分享或表情可能无法解析。路径/正文哈希归属是有限的格式适配规则，不能保证所有版本的资源命名均适用。

上游固定版本：BlueMatthew/WechatExporter 1.9.5.13 x64 CLI。已知 Windows 版 --format 行为不可靠，所以 TXT 不依赖其生成。README 的下载链接或支持格式不替代本项目实测。

本仓库测试使用完全合成的 Apple/微信结构，不会接触用户备份。通过测试意味着本项目对这些明确结构和异常输入行为符合预期，不代表所有 iOS/微信版本真实备份兼容。新设备与微信版本需要单独记录实际验证；未经验证不宣称兼容。

限制：不创建手机备份；不获取密钥；不解密加密备份；不自动合并分片；不自动确定压缩字典；不补齐已删除聊天；不证明全部手机历史已覆盖；不自动清理或上传。
