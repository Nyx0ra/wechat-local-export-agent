# 可直接交给本机 AI agent 的任务模板

请阅读本项目 AGENTS.md、README.md 和 docs/agent-runbook.md 后，在本机执行导出，不要仅给教程。

- 平台：Windows，本人的 iPhone 微信。
- 联系人：填写备注/昵称/微信号；多候选请核对。
- 微信账号：已知时填写；不要默认选第一项。
- 范围：填写完整会话，或明确含时区的起始时间与结束时间，采用起始包含、结束不包含。
- 备份：填写明确的本地设备备份目录，或先检查并协助我完成新的 Apple 本地备份。
- 工作目录：在 Git 与云同步之外创建新目录。
- 产物：HTML 连同附件、UTF-8 TXT、export-report.txt。

不要上传聊天、附件、备份、密钥或原日志；终端只展示统计及错误摘要。密码和身份操作由我在手机/系统界面完成。默认关闭上游转换；需要时先落实离线环境。缺失字典或附件必须说明，不猜写正文。

请持续执行至实际生成并验证文件，或遇到明确需要我操作的阻塞。最后给出绝对路径、记录与媒体统计、通过/未验证项。不要自动清理源备份或工作数据，不要发布到 GitHub。
